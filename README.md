# Shruti — offline read-aloud for Windows

**श्रुति · "that which is heard."** Drop in a PDF, a Word file, an e-book or a scanned page, press play, and listen. Shruti reads with natural voices, entirely on your PC.

**Product page, pricing and FAQ:** https://pcmadankumar.github.io/shruti.html

## Download

Get the latest installer from **[Releases](https://github.com/pcmadankumar/shruti-releases/releases/latest)**: `Shruti-Setup-<version>.exe`.

- Every feature is free for 15 days. After that, a licence key from Gumroad unlocks Shruti on up to 2 PCs.
- Requires Windows 10 or 11 (64-bit) and about 1 GB of disk space. No administrator rights needed.
- The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Choose **More info → Run anyway**.
- Installed copies update themselves from this page.

## About this repository

This repository holds **installers only**. Shruti's source code is private. Open-source components and voice models included in Shruti are listed, with their licences, in `THIRD-PARTY-NOTICES.txt` in the install folder.
